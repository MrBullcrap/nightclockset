# nightclockset

Night clock app for Android. A fullscreen bedside clock built with Apache
Cordova: auto day/night colors based on sunrise/sunset, an animated
gradient background, and ambient-light-driven screen brightness.

## Prerequisites

- [Node.js](https://nodejs.org/) (includes npm)
- [Android Studio](https://developer.android.com/studio) or the standalone
  Android command-line tools, with:
  - Android SDK Platform 34
  - Android SDK Build-Tools
- A JDK (17+) — bundled with recent Android Studio installs
- `ANDROID_HOME` (or `ANDROID_SDK_ROOT`) pointing at your Android SDK install

## Build

```sh
npm install
npx cordova platform add android
npx cordova build android
```

The debug APK is written to
`platforms/android/app/build/outputs/apk/debug/app-debug.apk`.

## Install on a device

With a device connected over USB (developer options + USB debugging
enabled) or an emulator running:

```sh
npx cordova run android
```

Or install the built APK directly:

```sh
adb install -r platforms/android/app/build/outputs/apk/debug/app-debug.apk
```

## Notes

- `plugins/` and `platforms/` are the only two paths carrying custom
  source in this repo that Cordova doesn't auto-generate — `plugins/`
  holds this project's own native plugins (screen pinning, light sensor,
  brightness control) and is intentionally committed; `platforms/` is
  fully regenerated by `cordova platform add android` and should never be
  committed.
- On first launch, grant the location permission prompt so sunrise/sunset
  day-night switching works. Location is optional — turn off "Use
  Sunset/Sunrise" in Settings to skip it.
- Double-tap the clock to open Settings.
